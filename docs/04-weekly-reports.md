# Weekly reports

Five minutes a week. Add a new section at the top; never edit an old one.

The value is entirely in writing them **while it is happening**. What took four
hours and why is invisible a month later, and it is exactly what your journal
needs.

## Week of: September 21–27, 2026

## What changed this week

- Connected the React frontend to an Express backend and Neon PostgreSQL database.
- Added database tables for players, paddles, and matches.
- Added user registration, login, logout, and session authentication.
- Connected Player Match to the database and added match requests and acceptance.
- Added match result recording and automatic updates for wins, losses, and points.
- Connected the Leaderboard to the database.
- Deployed and tested the frontend through GitHub Pages.
- Improved the registration form styling and responsive layout.

## Why

These changes were made to turn PaddleMatch from a frontend prototype into a working full-stack application. The database and API allow player accounts, match requests, results, and leaderboard information to be stored and updated.

## What broke or what I got stuck on

The main challenges were connecting the frontend, backend, and database correctly and setting up authentication. I also encountered a GitHub Pages routing issue and some registration form styling problems, which required additional testing and CSS adjustments.
